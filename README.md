## 🗺️ 学习路径建议

1. **入门阶段（掌握基础）**：先看第一章，理解 Git 的「工作区 → 暂存区 → 版本库」模型，这是后续一切操作的地基。
2. **进阶阶段（日常高频）**：再看第二章分支管理与第三章历史操作，覆盖日常开发中 80% 的场景。
3. **协作阶段（团队/开源）**：第四章讲清楚远程仓库与 GitHub 的一整套流程，包括 PR、CI/CD；第八章补充平台深度功能与协作规范。
4. **实战阶段（动手实践）**：按第九章的场景演练 + 练习题自测，遇到报错翻第七章「对号入座」。
5. **高手阶段（效率与底层）**：第五章的别名、钩子、子模块等技巧，以及第十章的仓库瘦身与性能优化是拉开差距的地方。
6. **冲刺阶段（求职面试）**：面试前突击第六章，每道题都配有「答案要点 + 相关命令」。

## ⚡ 快速速查

```bash
# 最常用的几个进阶命令
git log --oneline --graph --all          # 查看完整提交图谱
git rebase -i HEAD~3                     # 交互式改写最近 3 次提交
git cherry-pick <commit-id>              # 把某个提交复制到当前分支
git stash                                # 临时保存工作区修改
git revert <commit-id>                   # 安全撤销已推送的提交
git reflog                               # 找回被 reset 丢失的提交
git bisect start                         # 二分定位引入 bug 的提交
git worktree add ../release v2.0         # 同时检出多个分支到不同目录
git clone --filter=blob:none --sparse <url>  # 按需克隆大仓库
git filter-repo --path '*.zip' --invert-paths # 从历史中抹掉大文件
```

## 📝 注意事项

- 文中命令均在 Windows / macOS / Linux 通用（PowerShell、bash、zsh 均可直接使用）。
- 所有 `git` 命令可直接复制运行，涉及路径或用户名的部分请按实际情况替换。
- 学习时建议准备一个练习仓库，边读边敲，效果最佳。
